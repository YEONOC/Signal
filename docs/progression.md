# Progression System (Run 종료 강화)

## 개요

Run 종료 시 초과 Signal에 따라 **자동 랜덤 강화** 적용.
플레이어 선택 없음 — 외부(인간 조작자) 강화 연출.

---

## 계산 공식

```
Bonus       = max(0, FinalSignal - TargetSignal)
BonusPoint  = floor(Bonus / 25)   // 초과 25마다 1포인트
강화 횟수   = BonusPoint만큼 랜덤 강화 적용
```

---

## 강화 풀

| 스탯 | 1회 강화량 | 가중치 | 최대 중첩 | 상한(cap) |
|---|---:|---:|---:|---:|
| 이동속도 | +4% | 30 | 3회 | +12% |
| 추출 속도 | +6% | 25 | 3회 | +18% |
| 배터리 최대치 | +8 | 20 | 3회 | +24 |
| 스캔 범위 | +6% | 15 | 3회 | +18% |
| 배터리 소모 감소 | -4% | 10 | 3회 | -12% |

---

## 구현 규칙

- 동일 스탯 최대 3회 중첩 제한
- 희귀 스탯(가중치 낮을수록) 높은 임팩트
- 상한 초과 강화는 스킵하고 재추첨
- 강화 결과는 Run 종료 화면에 표시 (UI는 결과만 수신, 로직 소유 금지)

---

## 구현 담당 클래스

- 계산 및 적용: `USignalRunSubsystem` (Run 상태 소유자)
- 강화 풀 데이터: `USignalRunConfig` 또는 별도 `USignalProgressionConfig`
- UI 표시: Run 종료 화면 위젯 (이벤트 수신만)
